# Frontend (React + TypeScript)

This folder contains the React UI (Vite + TypeScript).

Live URLs:

- Frontend: https://frontend-sand-eight-62.vercel.app
- Backend API: https://calculator-backend-9law.onrender.com

Use these commands:

```bash
npm install
npm run dev
npm test
npm run test:coverage
npm run build
```

For setup, API contract, deployment, and design decisions, use the root documentation in [README.md](../README.md).
